# 🧪 Read one API test

> 🟡 **In progress** — no learner answer yet. About 5–10 minutes; no code changes needed.

Read the [short note and actual LMS example](../notes/jest-and-supertest.md).

1. Which tool sends the HTTP request, and which tool runs the test and checks the result?
2. If the endpoint returns `200` while the assertion expects `401`, does the test pass or fail? Why?
3. Identify the **act** and **assert** lines. What access rule is this test trying to protect?
