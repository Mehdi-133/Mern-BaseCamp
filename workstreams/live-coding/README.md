# 💻 Live-Coding Workspaces

Live-coding workspaces prioritize independent planning, implementation, verification, and explanation.

## Standard structure

```text
session-name/
├── README.md      # Scenario, rules, status, and next step
├── concepts/      # Concepts required by the scenario
├── notes/         # Short reminders, never hidden solutions
├── exercises/     # Learner-owned attempts
└── reviews/       # Checks, feedback, and reevaluations
```
