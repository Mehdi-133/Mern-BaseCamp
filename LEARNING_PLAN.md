## Chapter completion checklist

A chapter is complete only when the relevant items are true:

- [ ] Important examples were typed, predicted, and run.
- [ ] Required exercises were attempted before solutions were viewed.
- [ ] Exercise behavior was checked with useful inputs and edge cases.
- [ ] The main ideas were explained in the learner's own words.
- [ ] Confusing points were added to `notes/QUESTIONS.md`.
- [ ] New vocabulary was added to `notes/GLOSSARY.md` when useful.
- [ ] The chapter README, `PROGRESS.md`, and `sessions/CURRENT.md` were updated.
- [ ] The learner approved any Git checkpoint or commit.
