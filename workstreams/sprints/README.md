## 🗂️ Standard structure

```text
sprint-name/
├── README.md
└── briefs/
    └── brief-name/
        ├── README.md
        ├── brief-content/
        ├── brief-analysis/
        ├── concepts/
        ├── notes/
        └── exercises/
```

Only add `feedback/` or `deliverables/` when the brief actually needs them.
