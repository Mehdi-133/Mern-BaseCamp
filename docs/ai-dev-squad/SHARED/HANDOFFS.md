# 📬 Handoff template

Copy this block into the relevant project's report for every ownership transfer:

```text
Project / Jira issue (or explicitly uncreated proposal):
Objective / acceptance criteria:
Repository / branch / full HEAD:
Environment / permitted file scope:
From role / next responsible role:
Files and artifacts read or changed:
Completed actions:
Executed checks / exact results:
Untested or skipped checks / reason:
Known issues / risks / open decisions:
Source of truth / evidence links:
Next action / observable completion check:
Owner approval required, if any:
```
