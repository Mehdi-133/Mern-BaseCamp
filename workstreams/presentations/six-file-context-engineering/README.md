# 🧭 AI with Context — Think Like an Engineer

> 🟡 **Workshop preparation** — researched on 28 October 2026. Materials prepared; learner understanding, demo execution and rehearsal remain unverified.

**The idea:** give an AI coding assistant a reliable project briefing, ask for one clear change, and check the result before recording progress.

This workshop follows **JavaScript Mastery's Six-File Context System**, identified in the learner-supplied ZIP. Ghost AI is the guide's example project, a collaborative system-design tool; it is not a separate engineering methodology. Its build was not independently reproduced here.

## 👀 Start with the visual

![Six context files explain the product, architecture, code rules, AI workflow, interface and current progress; an entry point connects them to one scoped specification.](concepts/six-file-context/images/context-map.png)

**Read the map:** each file answers a different project question. The entry point tells the assistant where to look. A feature specification describes today's change; tests and review establish whether it works.

## 🎯 Why learn this?

- Practise explaining a product before asking AI to implement it.
- Make architectural decisions and team conventions visible.
- Learn to define observable success and review generated code.
- Preserve useful decisions when switching sessions or collaborators.
- Keep your own reasoning active: explain the change without asking AI again.

These are learning goals and expected uses, not measured gains from this workshop.

## 🚀 One next step
